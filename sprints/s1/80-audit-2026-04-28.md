# Sprint 1 Audit: 2026-04-28

## Purpose

This document records the first full repo-to-plan audit for Sprint 1. It is meant to separate what is already implemented from what is only planned, and to define the next execution wave for worker agents.

## Repo-State Summary

- The replay path is real, not speculative: preprocessed media can be replayed over Quinn and captured by the server into raw JSON reports.
- The harness is real, not just scaffolded: it can run local suites, analyze existing raw reports, and emit processed summaries plus per-run AMC analysis.
- The media and semantic path is real, not just designed: preprocessing scripts generate replay manifests with semantic hints that the harness consumes.
- The Linux VPS path is partially real: the host-side runner exists, the compose topology matches it, and runner hardening landed, but the end-to-end Linux validation record is still missing.
- Baseline controller selection is now implemented and locally evidenced for `cubic` and `bbr`.
- A live AMC preview transport path now exists through Quinn public hooks, with one local runtime proof artifact showing sender-driven utility telemetry on the wire.
